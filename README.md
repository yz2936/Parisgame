# Paris Time Machine

A browser-based educational city-building simulation MVP. Rebuild a simplified Paris across Medieval, Haussmann, and Belle Epoque eras with grid building, low-poly 3D visuals, visitor flow, stats, missions, educational insight cards, and local saved progress.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech stack

- Vite
- React
- TypeScript
- Three.js via @react-three/fiber
- @react-three/drei
- Zustand
- localStorage persistence
- Procedural low-poly geometry only
